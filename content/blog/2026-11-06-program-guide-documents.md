結論から言うと、自治体の補助金の申請で最も多く求められるのは「事業計画書」で、次が「登記事項証明書（法人の場合）」「納税関係の書類」です。当サイトが公式ページを読んで制度ガイドにした270件のうち、必要書類が読み取れた232件を数えると、5点以上の書類を求める制度が153件（66%）ありました。書類は、申請の直前にまとめて集めようとすると、役所で発行を待つものから間に合わなくなります。

この記事は、制度ガイドの元データ（data/program-details.json。公式ページの本文から読み取った事実を、2026年10月17〜18日に確認したもの）を数え直したものです。全国の自治体制度の全数ではなく、当サイトが優先して公式ページを取得した制度の集計です。必要書類の欄が空の38件（270件のうち）は、ページに書類の記載がなかったため、集計に含めていません。

## 1制度あたりの書類の点数：5点以上が153件

必要書類として読み取れた項目の数を、制度ごとに数えました（書類の項目は、公式ページの書き方に従っており、「申請書」と「様式第1号」を別々に書く自治体もあるため、点数は目安です）。

| 読み取れた書類の点数 | 制度の件数 | 232件に占める割合 |
| --- | --- | --- |
| 1点 | 22 | 9% |
| 2点 | 14 | 6% |
| 3点 | 23 | 10% |
| 4点 | 20 | 9% |
| 5〜6点 | 57 | 25% |
| 7〜8点 | 58 | 25% |
| 9点以上 | 38 | 16% |

読み方は2つあります。1つ目は、書類が3点以下の制度は59件（25%）にとどまり、4分の3は4点以上を求めることです。「申請書を書いて出せば終わり」という制度は、少数派です。2つ目は、9点以上の制度は38件あります。点数の最大は10点で、創業して店舗を開く際の内装費を補助する制度や、移住して創業する人の改修費を補助する制度などがありました。

## どんな書類が多いか：語句での件数

必要書類の文章に、次の語句が含まれていた制度の件数です。1つの制度が複数に入るため、合計は232になりません。語句での機械的な数え方なので、書き方の違いで拾えていないものもあります。

| 書類の種類（数えた語句） | 件数 | 232件に占める割合 |
| --- | --- | --- |
| 事業計画書・事業計画（「計画書」を含む） | 139 | 60% |
| 誓約書・同意書 | 91 | 39% |
| 登記事項証明書・履歴事項全部証明書 | 86 | 37% |
| 納税証明書・納税状況・滞納がないことの確認 | 78 | 34% |
| 決算書・確定申告書・貸借対照表など | 48 | 21% |
| 収支予算書・収支計画 | 48 | 21% |
| 領収書・請求書 | 48 | 21% |
| 開業届（個人事業の開業の届出） | 47 | 20% |
| 見積書 | 65 | 28% |
| 住民票・住民登録の確認 | 37 | 16% |
| 賃貸借契約書・契約書 | 35 | 15% |
| 通帳（口座）の写し | 25 | 11% |
| 写真 | 23 | 10% |
| 許可証・免許など | 12 | 5% |

注目したい点は3つあります。

1. **事業計画書は6割**：自治体の小さな補助金でも、計画書を求める制度が139件あります。書き方は[事業計画書の書き方の基本](../basics/business-plan.html)や、[数値計画の書き方の記事](2026-10-16-numerical-plan-tips.html)で確かめられます。
2. **見積書は65件（28%）**：金額の根拠として出す書類です。取り方の注意は[見積書（相見積もり）の記事](2026-10-15-aimitsumori-estimate-tips.html)にまとめています。
3. **領収書・請求書は48件**：申請時ではなく、事業を終えたあとの実績報告で出す書類も、あわせて書かれている制度があります（書き方は自治体で違います）。事業が終わったあとの書類の整え方は、[実績報告の記事](2026-10-20-performance-report-documents.html)で扱っています。

## 対象者の条件で「滞納なし」を求める制度：112件

必要書類の表で納税関係の書類が78件だったのに対し、対象者の条件の文章に「滞納」の語が含まれる制度は、270件のうち112件（41%）ありました。納税証明書を書類として求める制度より、「滞納がないこと」を条件にしている制度のほうが多い計算です。書類として求めない場合でも、自治体が内部で納税状況を確認することがあるため、条件としては同じ重さです。

そのほかの対象者の条件を、同じように数えました。

| 対象者の条件の語句 | 件数 | 270件に占める割合 |
| --- | --- | --- |
| 中小企業（者） | 160 | 59% |
| 創業・開業 | 87 | 32% |
| 暴力団の排除 | 28 | 10% |
| 過去の受給や交付についての記載 | 34 | 13% |
| 従業員数の記載 | 33 | 12% |
| 大企業・みなし大企業の除外 | 22 | 8% |

「過去に受給した人は対象外」「同じ経費で他の補助金を受けていない」といった記載がある制度が34件ありました。他の制度を併用したい場合は、先にこの条件を確かめます。

## 使い方：書類を3つの順番で準備する

1. **役所・法務局で発行を待つ書類を先に動かす**：登記事項証明書、納税証明書、住民票は、窓口や郵送で発行を依頼する書類です。取得日から制度によっては発行日からの有効期間が決まっていることがあるので、公式ページで確認してから取ります。
2. **事業計画書と見積書を、並行して進める**：見積書は、業者への依頼と回答の待ち時間があります。計画書の金額と合わせる必要があるため、同時に動かします。
3. **誓約書・同意書は、最後でよい**：様式は公式ページで配布されます。内容（暴力団の排除、納税状況の確認への同意など）を読んでから署名します。

どの書類が必要かは、制度ごとに違います。[制度ガイド一覧](../programs/index.html)で、気になる制度の「必要書類」の欄を開き、一覧にない制度は[市区町村から探すページ](../area/index.html)から公式ページへ進んでください。

## 参考情報の注意

この記事の数字は、2026年10月17〜18日に公式ページを読んだ時点の、当サイトの集計です。必要書類は、公募回や年度で変わります。補助金・助成金は、申請しても受給できるとは限りません。実際の申請は、必ず各自治体の公式ページで最新の要項を確認してください。
