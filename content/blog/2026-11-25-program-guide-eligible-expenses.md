結論から言うと、自治体の補助金で対象経費に挙がりやすいのは、**機械・設備・備品（102件）、広告・宣伝・ホームページ（73件）、委託・外注（71件）、内装などの工事（61件）**です。ただし、どの経費が中心になるかは制度の目的でまったく違い、創業の制度では工事・家賃・登記の費用まで対象になる一方、展示会の制度では出展料がほぼすべてです。申請の前に、**自分が使いたい経費が、その制度の「対象経費」の欄に名前で書かれているか**を先に確かめると、制度選びの時間を減らせます。

この記事は、当サイトの制度ガイド（自治体）の材料（data/program-details.json。公式ページの本文から読み取った事実で、確認日は2026年10月17〜18日）を、2026年11月25日に数え直したものです。

## どのデータを、どう数えたか

- 公式ページから内容を読み取れた自治体の制度270件のうち、「対象経費」の欄に記載があるのは246件です。
- このうち、制度の種類が「融資」の24件は、欄に書かれているのが資金の使い道（運転資金・設備資金など）のため除き、**222件**（市区町村194件、都道府県28件）を集計しました。
- 数え方は、欄の文章に決まった語句（「備品」「広告」「委託」「改装」「家賃・賃借」など）が含まれるかどうかです。1件の制度が、複数の経費に数えられます。
- 全国の自治体制度の全数ではなく、当サイトが優先して公式ページを読んだ制度の集計です。

### どう読むか

- **人件費は8件（4%）だけ**です。8件は、石巻市・長野県・鳥取県の創業・スタートアップの制度、東京都・松本市・沼津市の研究開発の制度、旭川市のものづくりの制度、葛飾区のデジタル化の制度でした。自社の従業員の給与を補助に入れたいときは、対象の制度がかなり限られます。
- **家賃は31件**ですが、当サイトの別の集計では、家賃を対象外と書く制度も12件ありました（[対象外の経費を数えた記事](2026-11-07-program-guide-excluded-expenses.html)）。同じ「家賃」でも、制度によって扱いが逆になります。
- 欄に名前がない経費は、対象にならないと考えて準備するのが安全です。「その他市長が認める経費」のような書き方の扱いは、窓口で確かめてください。

## 目的別に見ると、中心になる経費がまったく違う

制度の分類ごとに、多い経費を並べました（件数は、その分類の制度のうち、その経費を挙げる数）。

| 制度の分類 | 制度の数 | 多い経費（上位） |
| --- | --- | --- |
| 創業・起業 | 63件 | 広告31件、機械・備品30件、工事29件、家賃16件、委託14件、登記の費用11件 |
| 販路開拓・PR | 29件 | 展示会の出展27件、広告16件、委託14件 |
| 人材・雇用 | 23件 | 研修9件、機械・備品7件、人材紹介・求人6件 |
| 設備投資・省エネ | 21件 | 機械・設備19件、工事4件、ソフトウェア4件 |
| 空き店舗・商店街 | 17件 | 工事16件、機械・備品11件、家賃6件 |
| IT・デジタル | 17件 | ソフトウェア・クラウド15件、研修6件 |
| 研究開発・新事業 | 13件 | 委託11件、機械・器具11件、原材料・試作10件、産業財産権6件 |
| 事業承継 | 11件 | 専門家6件、委託6件 |

ここから分かるのは、**創業の制度が、もっとも幅広い経費を対象にしている**ことです。店の改装（29件）と家賃（16件）を両方挙げる制度があり、登記の費用（11件）には、つくば市・松戸市・春日部市・八戸市・豊中市のように、法人設立の登録免許税や定款認証の手数料だけを対象にする制度が含まれます。逆に、販路開拓の29件のうち27件は展示会の出展を挙げていて、広告（16件）より多くなっています。

空き店舗の17件は、16件が工事を挙げています。空き店舗の制度は、**「家賃の補助」よりも「入居するときの改装の補助」が中心**と読めます。

## 金額の条件：備品は「1点いくら以上」が決まっていることがある

対象経費の欄や注意書きに、備品や工事の金額の下限を書く制度があります。

| 制度 | 書かれている下限 |
| --- | --- |
| 郡山市スタートアップ支援補助金 | 設備・備品は耐用年数1年以上、取得金額が1点当たり10万円以上 |
| 前橋市まちなか開業支援補助金 | 備品は耐用年数1年以上で、取得価額1品が10万円以上 |
| 鯖江市創業スタートアップ支援事業補助金 | 備品購入費は10万円以上のもの |
| 伊勢崎市創業促進・事業承継サポート補助金 | 備品の単価が税抜3万円以上、改装の工事経費の合計が税抜10万円以上 |
| 上越市創業スタートアップ支援補助金 | 1点の購入金額が3万円を超える備品 |
| 新居浜市創業促進補助金 | 作業機械・備品類は単価2万円（税抜）以上 |
| 日立市店舗・オフィス開設支援事業 | 備品は1個あたりの取得価格（税込）が1万円以上 |
| 川口市商店改修事業補助金 | 市内業者が行う税抜き20万円以上の工事 |

小さな備品をたくさん買う計画だと、合計額が大きくても、1点ずつの単価が下限に届かず対象外になることがあります。税抜か税込かも、制度で違います。

## 工事は「市内の業者に発注」が条件になることがある

工事や改装を対象にする制度では、発注先を地域内の業者に限る記載が**12件**ありました（「原則」を含む）。たとえば、弘前市空き店舗対策事業費補助金は「工事の施工は弘前市内の業者に限る」とし、さらに「市内に本店を有する市内業者3者以上に工事見積書を依頼し、交付申請時にすべて提出する」と書いています。郡山市スタートアップ支援補助金は「市内企業による施工に限る」、伊勢崎市創業促進・事業承継サポート補助金は「原則、市内の施工業者・販売業者への発注に限る」です。太田市DX推進補助金は、システムの導入でも市内業者への発注を対象にしています（市内業者で施工できない場合などは市外も可）。

市外の知人の工務店に頼む予定だった場合、そのままでは対象外になる可能性があります。見積もりを取る前に、発注先の条件を確かめてください。相見積もりの取り方は、[見積書の取り方の記事](2026-10-15-aimitsumori-estimate-tips.html)にまとめています。

## 申請の前に確かめる順番

1. 使いたい経費（改装・備品・広告・家賃など）を書き出す。
2. [制度ガイド（自治体）の一覧](../programs/index.html)で、地域の制度の「対象経費」の欄に、その経費の名前があるかを見る。
3. 備品の単価の下限、税抜・税込、発注先（市内業者か）の条件を確かめる。
4. 対象外の経費（消費税・汎用品・交付決定前の発注など）を、[対象外の経費を数えた記事](2026-11-07-program-guide-excluded-expenses.html)と照らし合わせる。

地域で探すときは、[補助金をさがす](../search.html)で市区町村と目的を指定すると、該当する自治体の制度がまとまって出ます。
