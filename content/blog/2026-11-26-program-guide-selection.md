結論から言うと、**自治体の補助金は「審査で選ばれる制度」と「早く出した順の制度」で、準備の中身がまったく違います**。当サイトが公式ページから読み取った自治体の制度270件のうち、審査会・面接・プレゼンテーションなどで採否を決めると書いている制度は28件、先着順と書いている制度は23件でした。前者は計画書の中身と本人の説明が問われ、後者は書類を早く、不備なくそろえることが問われます。

この記事は、当サイトの制度ガイド（自治体）の材料（data/program-details.json、公式ページの確認は2026年10月18日まで）のうち、中身を読み取れた270件の概要・対象者・申請の流れ・注意書きの欄を、2026年11月26日に読み分けたものです。言葉の表れ方で候補を拾い、1件ずつ文脈を確かめて分類しました。

## 選び方の内訳：選考型28件、先着順23件

| 採否の決め方（公式ページの記載） | 件数 | 270件に占める割合 |
| --- | --- | --- |
| 審査会・審査委員会・面接・プレゼン・採択件数などで選ぶ（選考型） | 28件 | 10% |
| 先着順で受け付ける | 23件 | 9% |
| 「先着順ではない」と明記 | 2件 | 1% |
| 上のどれも書かれていない | 217件 | 80% |

### どう読むか

- **8割の制度は、決め方をはっきり書いていません**。ただし、書いていない217件のうち89件は「予算に達し次第終了」などの記載があり、実際には早い者勝ちに近い制度も含まれます（注意書きの集計は[制度ガイド270件の「注意書き」を数えた記事](2026-11-01-program-guide-cautions.html)にあります）。
- 「書類審査」とだけ書く制度（交付決定までの手続きとしての審査）は、選考型に数えていません。採否を競う仕組みが読み取れる制度だけを、選考型にしました。
- 「先着順ではない」と明記するのは、大阪府の[中小事業者の脱炭素化に係る自主的取組支援補助金](../programs/osaka-datsutanso-jishu.html)と、[富山県脱炭素化モデル中小企業育成事業費補助金](../programs/toyama-datsutanso-model.html)の2件でした。

**県の制度に先着順の記載は1件もありません**。一方、**設備投資・省エネは22件中8件が先着順**で、LED照明や省エネ設備、太陽光発電など、対象の設備が決まっていて審査の余地が小さい制度に多く見られました。創業・研究開発は選考型が目立ち、事業の中身を比べて選ぶ形です。

上限額にも差があります。上限額が100万円を超えると書かれた制度は、選考型28件のうち10件（東京都の課題解決型技術開発促進事業の2,000万円、長野県スタートアップ誘致・創出強化事業補助金の1,000万円など）でした。先着順23件では、kWあたりの単価で決まる2件を除き、100万円を超えるのは所沢市空き店舗活用・新規創業支援出店補助金の120万円の1件だけでした。

## 選考型28件：半数は本人の説明が要る

選考型28件のうち15件は、申請者本人によるプレゼンテーション・面接・審査会への出席を書いています（那覇市は「書類審査またはプレゼンテーション審査」）。

| 例（公式ページの記載から） | 選び方 | 時期・件数の記載 |
| --- | --- | --- |
| [大分市創業者応援事業補助金](../programs/oita-city-sogyosha-ouen.html) | 本人が約10分のプレゼン | 毎月第3火曜日までの申請分を、翌月上旬の審査会で審査 |
| [長岡市学生起業家育成補助金](../programs/nagaoka-city-gakusei-kigyoka.html) | 回ごとの審査会 | 毎月募集し、審査会は翌月 |
| [金沢市 地域連携若者起業家支援事業](../programs/kanazawa-city-wakamono-kigyoka-shien.html) | 一次（書類）・二次（面接） | 採択件数は5件程度、面接は令和8年12月下旬 |
| [デジタル技術活用促進助成事業（DX導入）](../programs/edogawa-dx-donyu.html)（江戸川区） | 一次（書類）・二次（プレゼン） | 二次審査は令和8年12月10日 |
| [姫路市ものづくり開発奨励補助金](../programs/himeji-city-monozukuri-kaihatsu.html) | 検討会議でプレゼン | 応募多数なら書類審査で上位10社程度に絞る、交付予定は3件程度 |
| [川口市DX推進補助金](../programs/kawaguchi-city-dx-suishin.html) | 採択予定件数を示す | 25件程度 |
| [厚木市 中心市街地の空き店舗出店支援](../programs/atsugi-city-akitenpo-shuten-shien.html) | 審査会で総合的に審査 | 審査会は年4回の予定 |

採択件数を数字で書く制度は、川口市（25件程度）、旭川市スタートアップ支援補助金（6件程度）、金沢市（5件程度）、旭川ものづくり支援補助金と姫路市（3件程度）などで、**枠が1桁の制度もあります**。旭川市の2つの制度は「プレゼンテーションに参加しない場合は、申請を辞退したものとして扱われる」と書いています。

選考型の準備で大事なのは、**審査会の日程から逆算すること**です。月ごとに審査会がある制度（長岡市・大分市）は、締切を1日過ぎると審査が1か月遅れます。那覇市中小企業者販路拡大支援事業は「審査会の1週間前かつ事業実施の1ヶ月以上前まで」の申請を求めており、事業の開始日から逆算しないと間に合いません。

## 先着順23件：「先着」にも細かい決まりがある

先着順の制度は、出せば早い順に決まる、とは限りません。公式ページには、次のような決まりが書かれていました。

| 決まり | 例 |
| --- | --- |
| 予算を超えた日の受付は抽選 | [大分市中小企業等賃上げ奨励金](../programs/oita-city-chinage-shoreikin.html)、[福山市 事業者向け創エネ・蓄エネ・省エネ設備導入等補助金](../programs/fukuyama-city-saiene-shoene.html) |
| 書類の不備で順番が前後する | [高松市特産品・伝統的ものづくり販売促進事業補助金](../programs/takamatsu-city-tokusanhin-hanbai.html)、文京区中小企業人材強化支援事業補助金 |
| 書類がそろった順に審査 | [所沢市空き店舗活用・新規創業支援出店補助金](../programs/tokorozawa-city-akitenpo-shuten.html) |
| 先着の枠を数で示す | [めぐろ中小企業省力化投資補助金](../programs/meguro-shoryokuka.html)（50社程度）、[豊島区 コラボチャレンジコース](../programs/toshima-collab.html)（令和8年度は先着3件） |

つまり先着順でも、**順番の基準は「書類が完全にそろった時点」**になることが多く、不備があれば後ろに回ります。日立市の2つの制度は、締切を令和8年11月30日としながら「先着順のため、期日前に募集を締め切る場合がある」と書いています。締切の日付だけを見て、後回しにしないことが大切な理由です。

## 申請の前に、確かめる順番

1. **決め方を確かめる**：公募要領で「審査会」「採択件数」「先着順」「予算に達し次第」の語を探します。どれもなければ、窓口に、採否の決め方と、今の申請の状況を聞きます。
2. **選考型なら**：審査会の日程と、プレゼン・面接の有無を確かめ、事業計画書を、口頭で説明できる形に整えます（書き方は[基本の知識：事業計画書](../basics/business-plan.html)）。
3. **先着順なら**：見積書・納税証明書など、時間のかかる書類を先にそろえ、受付開始日に、不備のない一式を出せるようにします。郵送の場合は、消印有効か必着かも確かめます。
4. **どちらでも**：交付決定の前に発注・契約をしてよいかを確かめます（申請の流れの集計は[制度ガイド205件の「申請の流れ」を数えた記事](2026-11-24-program-guide-flow.html)）。

## この集計の限界

- 数えたのは、当サイトが公式ページから読み取った材料の範囲です。要綱や公募要領にだけ書かれた決め方は、入っていません。「記載なし」は「決め方がない」という意味ではありません。
- 公式ページの確認は2026年10月18日までで、その後に変わった制度もありえます。受付が終わった制度も含みます。
