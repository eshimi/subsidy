結論から言うと、**自治体の補助金の「申請の流れ」は、公式ページでは途中までしか書かれていないことが多く、とくに交付決定のあとの手順（実績報告・請求）は、半分以上の制度で書かれていません**。当サイトが公式ページから読み取った自治体の制度270件のうち、申請の流れが書かれていたのは205件で、その中で実績報告に触れているのは85件（41%）、交付決定から実績報告・請求（支払い）までを通して書いているのは29件（14%）でした。

また、**「交付決定の前に発注・契約・着手してはいけない」という順番を、手順の中に書いている制度は35件**ありました。ここを読み落とすと、対象外になるおそれがあります。

この記事は、当サイトの制度ガイド（自治体）の材料（data/program-details.json、公式ページの確認は2026年10月18日まで）のうち、中身を読み取れた270件の「申請の流れ」の欄を、2026年11月24日に、言葉の表れ方で数えたものです。1件の制度が、複数の段階に数えられます。

## 手順の数：中央値は3段階

申請の流れの欄に書かれた手順の数を数えると、次のようになりました。

| 手順の数 | 制度の数 |
| --- | --- |
| 記載なし | 65件 |
| 1段階 | 18件 |
| 2段階 | 48件 |
| 3段階 | 40件 |
| 4段階 | 42件 |
| 5段階 | 19件 |
| 6段階 | 14件 |
| 7段階 | 13件 |
| 8段階 | 11件 |

流れが書かれた205件の中央値は3段階です。いっぽう、名前や分類から創業・起業の制度と見られる61件に絞ると、中央値は4段階に増えます。創業の制度は、事前の相談や審査会など、申請書を出す前後の段階が多いためです。

### どう読むか

手順が少ないのは、手続きが簡単だからとは限りません。「申請書を提出する」「交付決定を受ける」の2段階だけで、その後の実績報告や請求が公式ページに書かれていない制度もあります。その場合も、要綱や交付決定通知に、あとの手続きが書かれているのがふつうです。

## 段階ごとの件数：あとの手続きほど書かれない

流れが書かれた205件を、補助金・助成金などの172件と、融資・利子補給・保証料補助などの33件（名前や種類に融資・利子・保証料・資金を含むもの）に分けて数えました。

| 流れに書かれた段階 | 205件 | 補助金など172件 | 融資など33件 |
| --- | --- | --- | --- |
| 事前相談・事前登録・予約 | 28件 | 26件 | 2件 |
| 審査会・プレゼン・面接 | 22件 | 21件 | 1件 |
| 交付決定（決定通知） | 63件 | 62件 | 1件 |
| 交付決定の前に着手しない（着手前に申請） | 35件 | 35件 | 0件 |
| 実績報告・完了報告 | 85件 | 84件 | 1件 |
| 額の確定 | 38件 | 37件 | 1件 |
| 請求 | 51件 | 46件 | 5件 |
| 交付決定から実績報告・請求（支払い）まで通して記載 | 29件 | 29件 | 0件 |

融資などの33件では、交付決定や実績報告がほとんど出てきません。かわりに、「取扱金融機関に事前に相談し、貸付けについての了承を得る」（所沢市新規創業支援資金融資制度）や、「市の融資あっせん決定後、金融機関と信用保証協会等の審査を受ける」（西東京市 創業資金融資あっせん制度）のように、**金融機関と信用保証協会の審査が流れの中心**になります。補助金と同じ順番で準備すると、手戻りが出ます。

### 着手の順番は、こう書かれている

「交付決定の前に着手しない」を書く35件の書き方には、幅があります。

- 申請の時期で書く：「事業の着手前に、申請書類を窓口へ持参または郵送する」（墨田区デジタル技術活用支援補助金）
- 発注・契約まで具体的に書く：「交付決定後に発注、購入、契約等を行う」（大垣市スタートアップ支援事業補助金）
- 日数で区切る：「事業着手日より前に交付申請を提出する（原則、事業実施日の30日前まで）」（豊田市経営力強化支援補助金）
- 着手を届け出る：「補助事業着手届の提出」（姫路市創業者応援補助金）

**流れの欄に書かれていない残りの制度でも、交付決定前の着手を認めないことは多い**ため、35件という数字は「ほかは着手してよい」という意味ではありません。見積もりを取るのはよくても、発注・契約・支払いは交付決定通知を受け取ってから、と考えておくのが安全です。

## 事前相談と審査会：申請書の前後に時間がかかる

事前相談を手順に入れる28件には、相談先が市の担当課ではない例が目立ちます。豊島区の中小企業支援事業補助金（開業支援コース）は、としまビジネスサポートセンターの「補助金相談」を予約し、「事前相談完了後に交付申請をする」流れです。墨田区のデジタル技術活用支援補助金も、すみだビジネスサポートセンターで事業計画書を作成してから申請します。

審査会・プレゼン・面接を手順に入れる22件のうち、書類審査とプレゼン・面接の**二段階審査**を書いているのは、旭川市スタートアップ支援補助金、旭川ものづくり支援補助金、金沢市 地域連携若者起業家支援事業、長野県スタートアップ誘致・創出強化事業補助金、江戸川区のデジタル技術活用促進助成事業（DX導入）の5件でした。

審査の日程が決まっている制度もあります。大分市創業者応援事業補助金は、申請日を予約し、申請時に本人が約10分のプレゼンテーションを行い、「毎月第3火曜日までに申請を完了した事業者は、翌月上旬の審査会で審査される」流れです。横手市の起業・創業支援事業補助金は、申請者が出席する審査会で採択を決め、受理から決定まで2〜3週間程度としています。**着手したい日から逆算して、相談・審査に1か月前後を見込む**必要がある制度があることが、ここからわかります。

## 実績報告の期限：「完了後30日以内」と「早い日」

実績報告に触れる85件のうち、期限を「完了後○日以内」の形で書いているのは24件でした。

| 実績報告の期限（日数の書き方） | 件数 |
| --- | --- |
| 完了後30日以内 | 12件 |
| 1か月以内 | 3件 |
| 20日以内 | 4件 |
| 14日以内 | 2件 |
| 60日以内 | 2件 |
| 10日以内 | 1件 |

ほかに、日数ではなく「令和9年2月26日まで」のように、年度末に近い日付だけで書く制度が11件ありました。

注意したいのは、85件のうち12件が、「事業完了後30日以内、または令和9年2月26日（金）のいずれか早い日まで」（大垣市スタートアップ支援事業補助金）のように、**日数と日付の早いほうを期限にしている**ことです。年度の後半に事業を終えると、30日の余裕はなくなります。姫路市創業者応援補助金のように「事業完了後10日以内」と短い制度や、補助金の交付後に「事業開始以後2か年の状況を報告」する実施状況報告まで流れに書く制度もあります。

## 申請の前に、流れで確かめる5つのこと

1. **事前相談が必要か**：相談先（市の担当課か、商工会議所・支援センターか）と、予約の要否。
2. **審査の方法と日程**：書類だけか、プレゼン・面接があるか。審査会の開催月が決まっているか。
3. **着手してよい日**：交付決定通知を受けてから発注・契約するのか、着手届が必要か。
4. **実績報告の期限**：完了後の日数と年度末の日付の、どちらが早いか。
5. **支払いまでの段階**：額の確定・請求のあとに入金される。入金までの資金の手当ても、あわせて考える。
