結論から言うと、個人向けの自治体制度は「空き家・ブロック塀」と「耐震」に集中し、金額は分野によって数十倍違います。しかも、締切が書かれている制度は4分の1に満たないため、「いつまで」を自分で確かめる前提で探す必要があります。

この記事は、当サイトが掲載している個人向け（住まい・暮らし）の自治体制度2,246件を集計したものです（2026年10月26日時点、data/analysis-latest.json の resident）。都道府県の制度253件と市区町村の制度1,993件を含みます。数字は当サイトの掲載データから数えたもので、全国の制度の全数ではありません。

## 分野別の件数：空き家・耐震で806件、3割超

次の表は、分野ごとの制度数と、金額の中央値です。金額は、説明文にある円の表記から機械的に取り出した最大値で集計しています（1件あたりの上限額や、定額の給付額が混ざります）。

| 分野 | 制度数 | 全体に占める割合 | 金額の中央値 |
| --- | --- | --- | --- |
| 空き家・ブロック塀 | 414 | 18.4% | 40万円 |
| 耐震 | 392 | 17.5% | 100万円 |
| 太陽光・蓄電池 | 279 | 12.4% | 12万円 |
| 移住 | 259 | 11.5% | 100万円 |
| 子育て | 213 | 9.5% | 5万円 |
| バリアフリー・介護 | 158 | 7.0% | 25万円 |
| 省エネ住宅 | 156 | 6.9% | 20万円 |
| 医療・福祉 | 148 | 6.6% | 3万円 |
| 教育・学び | 148 | 6.6% | 8万1,000円 |
| EV・充電 | 79 | 3.5% | 20万円 |

空き家・ブロック塀（414件）と耐震（392件）を合わせると806件で、全体の35.9%です。この2分野は、住宅の安全や空き家対策という、自治体が力を入れやすい政策に結びついているためと考えられます（理由は当サイトの推測で、データから確かめたものではありません）。

読み方の注意が2つあります。第一に、件数が多い分野ほど金額が大きいわけではありません。太陽光・蓄電池は279件と3番目に多いのに、中央値は12万円です。第二に、中央値は「文中の最大値」から作っているため、実際にもらえる額は、条件や工事費によって下がります。

## 金額の幅：10〜50万円が最も多く、500万円以上は18件だけ

次の表は、金額帯ごとの制度数です。

| 金額帯 | 制度数 | 割合 |
| --- | --- | --- |
| 10万円未満 | 423 | 18.8% |
| 10〜50万円 | 681 | 30.3% |
| 50〜100万円 | 272 | 12.1% |
| 100〜500万円 | 397 | 17.7% |
| 500万円以上 | 18 | 0.8% |
| 金額の記載なし／率のみ | 455 | 20.3% |

10〜50万円の帯が681件で最も多く、500万円以上は18件（0.8%）にとどまります。個人向けの自治体制度の多くは「数万〜数十万円を補助する」性格で、事業者向けの大きな補助金とは桁が違います。一方で、455件（20.3%）は金額の記載がなく、「工事費の○分の1」のような率だけの制度も含まれます。この帯は、他の制度と金額を並べて比べられません。

## 締切：記載があるのは529件、76%は「書いていない」

締切について、同じデータは次のように分かれています。

- 締切が書かれた制度：529件（23.6%）
- 締切の記載がない制度：1,717件（76.4%）
- 書かれた529件のうち、すでに過ぎたもの：46件、30日以内に迎えるもの：50件、31〜60日：131件、61〜90日：52件、91〜180日：242件、それ以降：8件

締切の記載がない制度の多くは、「予算がなくなり次第終了」や「年度内随時受付」のような形だと考えられますが、データだけでは断定できません。大事なのは、記載がないことを「いつでも申請できる」と読まないことです。自治体の補助金は年度ごとの予算で動くため、予算の上限に達すると、締切より前に受付が終わる場合があります。

締切の月で見ると、書かれた制度のうち、2026年10月〜2027年3月に締切を迎える484件が91%を占めます。月別では、次のとおりです。

| 締切の月 | 制度数 |
| --- | --- |
| 2026年10月 | 47 |
| 2026年11月 | 75 |
| 2026年12月 | 108 |
| 2027年1月 | 66 |
| 2027年2月 | 66 |
| 2027年3月 | 122 |

年度末の2027年3月が122件で最多、次いで12月の108件です。年度内に使い切る前提の制度が多いことがうかがえます。なお、すでに締切を過ぎた46件は、来年度に同じ制度が再開される場合もあるため、「終わった制度」として捨てずに、次の年度の参考にします。

## 地域差：東京都が362件、鳥取県は8件

都道府県別の掲載数（都道府県の制度と、その域内の市区町村の制度の合計）では、東京都が362件で最も多く、千葉県123件、大阪府115件、神奈川県112件、埼玉県103件と続きます。少ないほうは、鳥取県8件、島根県11件、高知県12件、徳島県13件、岡山県17件です。

ただし、この差は「制度の多さ」だけでなく、当サイトが調べられた範囲の違いも含みます。鳥取県の8件は、「鳥取県には個人向けの制度が8つしかない」という意味ではありません。件数の少ない地域では、市町村の公式サイトや広報で、直接確かめることをおすすめします。

## この数字を、探すときにどう使うか

1. **分野を決めてから探す**：耐震と移住は金額が大きく、医療・福祉や子育ては小口の給付が中心です。目的が決まっているなら、[個人向けの分野別ページ](../personal/seismic.html)から入ると早く比べられます。
2. **住んでいる市区町村で絞る**：2,246件の89%（1,993件）は市区町村の制度です。[地域別のページ](../area/index.html)で、市区町村の名前から探します。
3. **締切の記載がなければ、窓口に聞く**：予算の残りや受付状況は、データに出ません。担当課に電話か問い合わせで確かめます。
4. **工事の前に申請する**：住宅関係の制度の多くは、契約や着工の前の申請が条件です。[補助金は後払いが基本](../columns/subsidy-paid-after.html)の考え方もあわせて確認します。

## 集計の限界

- 金額は説明文の円の表記から取り出したもので、実際の上限額と一致しない場合があります。
- 締切の記載がない1,717件は、期間が未定なのか、通年なのか、データだけでは判別できません。
- 件数は当サイトの掲載範囲の数字で、全国の制度の全数ではありません。
- この記事は参考情報で、受給を保証するものではありません。最新の金額・条件・締切は、必ず自治体の公式の案内で確認してください。
