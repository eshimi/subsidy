# ブログの投稿方法

記事は `content/blog/` に Markdown（`.md`）で書きます。`node scripts/build-blog.mjs` を実行すると、`public/blog/` に記事のページ・一覧・RSS（feed.xml）が作られます。

## 1. ファイル名

`YYYY-MM-DD-英小文字とハイフン.md` の形にします。日付は公開日です。

- 例：`2026-10-20-subsidy-basics.md`
- 日付の新しい順に一覧に並びます。ファイル名の英語部分が、ページのURL（`/blog/2026-10-20-subsidy-basics.html`）になります。

## 2. 先頭の設定（front matter）

ファイルの先頭に、`---` で囲んで書きます。

```
---
title: 記事のタイトル
description: 一覧と検索結果に出る説明（1〜2文）
date: 2026-10-20
updated: 2026-10-25
draft: false
---
```

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| `title` | はい | 記事のタイトル（ページの見出しになります） |
| `date` | はい | 公開日（`YYYY-MM-DD`） |
| `description` | いいえ | 説明文。省略するとタイトルが使われます |
| `updated` | いいえ | 内容を直した日。書くと「最終更新日」として表示されます |
| `draft` | いいえ | `true` にすると、ビルドに載らない下書きになります |

## 3. 本文の書き方

使えるのは次の書き方だけです。

- `## 見出し`：記事の節になります（枠で区切られた見出し）。最初の `##` より前の文章は「はじめに」になります。
- `### 小見出し`：節の中の小見出し
- 段落：空行で区切ります。同じ段落の中で改行したいときは、そのまま改行します。
- 箇条書き：`- 項目`（番号付きは `1. 項目`）
- 引用：`> 文章`
- 太字：`**太字**`
- リンク：`[リンクの文字](https://example.com/)`。サイト内のページは `../hantei.html` のように書きます（記事のファイルは `blog/` の中にあるため）
- コード：`` `文字` ``

表・画像・コードブロックは使えません。必要になったら、build-blog.mjs を広げてから使います。

## 4. 書いたあとの作業

```
node scripts/build-blog.mjs
node scripts/apply-nav.mjs   # ※メニューを変えたときだけ
```

生成された `public/blog/` と、変更したファイルをまとめてコミットし、ブランチに push します（サイトの更新と同じ手順です）。

## 5. 書くときの注意

- 制度の金額・締切・対象条件は変わります。数字を書くときは、公式の情報で確認した日付を明記してください。
- 確かめられていない内容は書かないでください。
- 他のサイトの文章を引用するときは、引用部分を短くし、出典のリンクを付けてください。
